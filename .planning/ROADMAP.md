# Roadmap

**Mode:** mvp

## Milestones

### Milestone 1: Foundation & Citizen Reporting (MVP)
The core pipeline allowing a citizen to submit a problem and have it intelligently categorized.

#### Phases

**Phase 1: Walking Skeleton**
- **Goal:** As a developer, I want to set up the foundational stack (FastAPI, React, Postgres) so that the app compiles, deploys, and can pass basic health checks end-to-end.

**Phase 2: Authentication & Database Schema**
- **Goal:** As a user, I want to authenticate via OTP so that role-based access controls are established for verifiers and universities.

**Phase 3: Citizen Reporting (Frontend + Local Queue)**
- **Goal:** As a citizen, I want to record a voice note or text report offline so that it syncs when I have connection.

**Phase 4: Problem Intelligence Engine (Backend AI)**
- **Goal:** As a verifier, I want incoming reports to be automatically transcribed, categorized, and clustered via embeddings so that duplicates are merged.

**Phase 5: University & Funder Portals**
- **Goal:** As a faculty member or mentor, I want to browse matched problems and track milestones so that projects progress toward funding approval.
